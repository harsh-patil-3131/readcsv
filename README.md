PERSONAL BUDGET TRACKER

This menu driven program is written to track money transactions.
It is written in C language.

header.h -> All structures and functions are defined in header.h

header.c -> Functions are written in header.c

main.c -> Menu driven program is written in main.c

To run code on terminal use commands as below:
>> gcc -Wall -c main.c header.c

>> gcc main.o header.o -o project

>> ./project
